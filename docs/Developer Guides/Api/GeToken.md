# Get Token

Every Woofed CRM API call needs a **JWT Bearer Token**. The token is generated by the admin panel and represents a specific user — every action you perform with that token is logged and authorised as if that user had performed it inside the UI.

## Step by step

1. Sign in to Woofed CRM with an **admin user**.
2. Open the admin panel:

   ```
   https://<your-subdomain>/motor_admin
   ```

   On Woofed CRM cloud this is usually `https://app.woofedcrm.com/motor_admin`. On a self‑hosted install, replace the host with your own.

3. Click on **`*` (Settings)** at the top of the panel.
4. Open the **Users** section.
5. Click **Add Column**, then fill in:
   - **Name:** `get_jwt_token`
   - **Type:** `ReadOnly`
6. Save the column. The new column will appear on the users grid; the value of that cell, for the row of the user you want to authenticate as, **is your token**.

Copy that value and use it as `Bearer <token>` in every request — see [**Authentication**](./authentication) for examples.

## After you have the token

- Quick first call: [**Getting started → Your first request**](./getting-started#4-your-first-request)
- Where to put the header: [**Authentication → Sending the token**](./authentication#sending-the-token)
- Keeping it safe: [**Authentication → Security best practices**](./authentication#security-best-practices)

:::caution Don't share this column with non‑admin users
The `get_jwt_token` column shows full access tokens. Make sure only trusted admin users can see the Users grid in the admin panel.
:::
